🚀 BCD-to-7-Segment Decoder CalculatorProyek Final Mata Kuliah Sistem DigitalAplikasi kalkulator interaktif berbasis Python yang mensimulasikan konversi bilangan desimal ke kode BCD (Binary Coded Decimal) dan menampilkannya melalui visualisasi Seven Segment Display.📝 Deskripsi ProyekKalkulator ini dirancang untuk mendemonstrasikan bagaimana sistem digital memproses input angka desimal, mengubahnya menjadi format biner 4-bit (BCD), dan melakukan decoding logika untuk menyalakan segmen-segmen tertentu pada display LED (Seven Segment).✨ Fitur UtamaAntarmuka Modern: Dibangun menggunakan library CustomTkinter untuk tampilan yang bersih dan mendukung tema gelap.Operasi Aritmatika Dasar: Mendukung Penjumlahan, Pengurangan, Perkalian, dan Pembagian.Visualisasi Real-Time: Display Seven Segment pada layar akan berubah secara otomatis setiap kali tombol ditekan atau hasil dihitung.Log Operasi Collapsible: Panel riwayat yang mencatat setiap langkah logika (Input -> BCD -> Output Segmen) yang bisa dibuka-tutup.Tabel Kebenaran: Fitur untuk menampilkan referensi tabel kebenaran BCD ke 7-Segment secara langsung di dalam aplikasi.🛠️ Prasyarat (Prerequisites)Sebelum menjalankan aplikasi, pastikan Anda telah menginstal Python dan library yang diperlukan:Bashpip install customtkinter Pillow
🚀 Cara MenjalankanClone repositori ini atau unduh file .py proyek.Pastikan Anda memiliki folder assets yang berisi file Tabel_Kebenaran.png.Jalankan program melalui terminal/command prompt:Bashpython main.py
